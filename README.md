# 📊 Retail Analytics Dashboard

A full-stack Retail Analytics Dashboard built with **React, TypeScript, Node.js, and Express** that provides interactive business insights from retail sales data. The application visualizes key performance metrics, sales trends, profitability, regional performance, and customer insights through an intuitive dashboard.

---

## 🚀 Features

- 📈 Interactive analytics dashboard
- 💰 KPI cards for:
  - Total Sales
  - Total Profit
  - Total Quantity Sold
  - Average Discount
  - Number of States
- 📊 Multiple interactive charts
  - Sales by Category
  - Profit by Category
  - Sales by Region
  - Profit by Region
  - Sales by Segment
  - Top 10 States
- 💡 Automated business insights
- 🔄 Refresh dashboard data
- 📥 Export original dataset as CSV
- 📱 Responsive modern UI
